# Busybox applets linked into the image.
#
# One applet name per line; blank lines and #-comments ignored.
# collect-rootfs.sh validates every name against `busybox --list` and fails the
# build on an unknown one, so this file cannot silently rot.
#
# Deliberately NOT here: bash, git, rg, fd, node, npm, tsc -- those are real
# binaries shipped alongside busybox and must not be shadowed by an applet.
#
# Also deliberately NOT here, though busybox provides them: su, login, passwd,
# mount, umount, chroot, dpkg, rpm, insmod, modprobe, init, reboot, poweroff,
# ifconfig, ip, route, telnetd, httpd, crond, syslogd. An agent sandbox has no
# use for privileged, daemon or network-configuration applets, and leaving them
# out is most of the point of an allowlist over `busybox --install`.
